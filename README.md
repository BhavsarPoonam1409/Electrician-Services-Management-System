# Electrician Services Management System

A web-based project developed using Python and Django to make electrician service booking easier. Users can explore available services, book a service, and manage their bookings through a simple interface.

This project was created as part of my learning journey to gain practical experience in Django web development, database management, and building a complete web application.

## Live Demo

🔗 **Live Website:** [Electrician Services Management System](https://electrician-services-management-sys.vercel.app/)

## Features

* View Available Electrician Services
* Book Electrician Services
* View Service Bookings
* Cancel Bookings
* Simple and User-Friendly Interface

## Technologies Used

* **Python** – Backend programming
* **Django** – Web framework
* **HTML** – Page structure
* **CSS** – Styling and layout
* **JavaScript** – Frontend functionality
* **SQLite** – Database
* **Git & GitHub** – Version control and code management
* **Vercel** – Deployment

## Project Overview

The main purpose of this project is to provide a simple platform where users can access electrician services and manage their bookings online.

Working on this project helped me understand how Django connects views, templates, URLs, and database models to build a functional web application.
